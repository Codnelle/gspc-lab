# ReportKit

ReportKit is a tiny practice project for the GSoC prep lab. It stores money
entries in reports and exports them as CSV.

## Requirements

- Python 3.8 or newer

## Getting started

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -e .
```

## Run the tests

```bash
pytest -q
```
